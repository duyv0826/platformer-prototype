# 04 · UI 系统

命名空间：`Prototype.UI`
目录：`Assets/Scripts/UI/`
文件数：**2 个**

UI 层的核心设计原则：**只订阅事件，不直接引用任何玩法对象**。
HUD 和 ResultUI 都是纯表现层，通过 EventBus 与 Core 交互。

## 4.1 HUD —— 游戏内 UI

**文件**：`Assets/Scripts/UI/HUD.cs`

Main 场景的实时游戏界面，全部通过 Subscribe 驱动。

### 序列化字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `scoreText` | Text | 分数显示文本 |
| `hintText` | Text | 提示文字（默认 / 达标后变更） |
| `comboText` | Text | 连击提示（combo ≥ 2 才显示） |
| `progressFill` | Image | 进度条填充 Image |
| `hearts` | Image[] | 生命心形数组（3 格） |
| `scoreFormat` | string | 分数格式化模板（默认 "分数: {0}"） |
| `targetScore` | int | 进度条上限 / 提示文字切换条件 |
| `maxLives` | int | 初始生命数 |
| `fullHeart` | Sprite | 满心心形（留空则用颜色区分） |
| `emptyHeart` | Sprite | 空心心形 |
| `hintDefault` | string | 默认提示语 |
| `hintDone` | string | 分数达标后提示语 |

### 事件订阅

```csharp
OnEnable:
    Subscribe<ScoreChangedEvent>(OnScoreChanged)
    Subscribe<LivesChangedEvent>(OnLivesChanged)
    Subscribe<ComboChangedEvent>(OnComboChanged)
    // 初始化界面显示

OnDisable:
    Unsubscribe 以上三个
```

### 回调逻辑

#### OnScoreChanged

```
- 更新 scoreText → "分数: {总分}"
- 如果总分 >= targetScore → hintText 换为 hintDone
- 更新进度条 → SetProgress(score)
```

进度条实现：`progressFill.rectTransform.sizeDelta = new Vector2(280f * ratio, 12f)`
（通过改变宽度实现填充，不是修改 Image.fillAmount）

#### OnLivesChanged

```
for (i = 0; i < hearts.Length; i++)
    hearts[i] = i < lives ? fullHeart : emptyHeart
    如果没有 emptyHeart → 用半透明 Color(0.2,0.2,0.2,0.5) 代替
```

#### OnComboChanged

```
if (combo >= 2) → comboText.text = $"连击 x{combo}！"，SetActive(true)
else           → SetActive(false)
```

### OnEnable 初始化顺序

1. 设置 hintText 默认文字
2. 设置 scoreText = "分数: 0"
3. SetProgress(0)
4. UpdateHearts(GameManager.Instance.Lives) —— 直接读取 GameManager 初始值
5. UpdateCombo(1)

注意：这里直接访问了 GameManager.Instance（不是通过 EventBus），因为 GameManager 在场景中一定比 HUD 先初始化。

## 4.2 ResultUI —— 结算界面

**文件**：`Assets/Scripts/UI/ResultUI.cs`

Result 场景的结算页，在 Start() 时读取 GameManager 快照一次性渲染，之后用户点「再玩一次」。

### 序列化字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `finalScoreText` | Text | 最终分数 |
| `collectText` | Text | 收集统计 "X / Total" |
| `starsText` | Text | 星级评价（★/☆） |
| `replayButton` | Button | 再玩一次按钮 |

### Start 渲染逻辑

```csharp
var gm = GameManager.Instance;

// 1. 最终分数
finalScoreText.text = $"最终分数: {gm.Score}";

// 2. 收集率
collectText.text = $"收集: {gm.Collected} / {gm.TotalCollectibles}";

// 3. 星级（按收集率）
float rate = gm.Collected / (float)totalCollectibles;
int stars = rate >= 1.0 ? 3 : (rate >= 0.8 ? 2 : (rate >= 0.6 ? 1 : 0));
starsText.text = new string('★', stars) + new string('☆', 3 - stars);
```

### 星级评定规则

| 收集率 | 星级 |
|---|---|
| 100% | ★★★ 三星 |
| ≥ 80% | ★★ 二星 |
| ≥ 60% | ★ 一星 |
| < 60% | 0 星 |

### 再玩一次

```csharp
replayButton.onClick.AddListener(() => {
    GameManager.Instance.ResetScore();     // 分数/生命/连击归零
    SceneManager.Instance.Load("Main");    // 回主关卡
});
```

## Canvas 结构

SceneSetupHelper.CreateHUD 搭建的 Main 场景 Canvas：

```
HUD Canvas (Screen Space Overlay)
├── ScoreText (Anchor: 左上, 26pt white)
├── HintText (Anchor: 底部居中, 20pt white)
├── ScoreBar
│   ├── ScoreBar (背景 Image, 半透明黑)
│   └── ScoreFill (填充 Image, 金黄 #FFD93D)
├── Heart_0 / Heart_1 / Heart_2 (锚点左上)
└── ComboText (默认 SetActive(false))
```

Result 场景 Canvas：

```
Result Canvas (Screen Space Overlay)
├── TitleText ("游戏结束")
├── FinalScoreText ("最终分数: XX")
├── CollectText ("收集: X / Total")
├── StarsText ("★★☆")
└── ReplayButton ("再玩一次")
```
