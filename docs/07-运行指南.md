# 07 · 运行指南

## 环境要求

| 组件 | 要求 |
|---|---|
| Unity | **2022.3.62f3c1**（LTS 长期支持版） |
| IDE | Visual Studio 2022（或 VS Code + Unity 插件） |
| 操作系统 | Windows / macOS / Linux |
| 美术素材 | Kenney Pixel Platformer 已在仓库中（501 文件） |
| 外部音频 | 无（全部程序化合成） |

### Unity 版本

**必须**使用 2022.3.62f3c1。ProjectVersion.txt 硬编码了这个版本。
如果 Unity Hub 里没有，先装这个版本。升级/降级可能导致：
- 脚本编译错误
- AssetDatabase GUID 变更
- 场景文件不兼容

## 快速启动（6 步）

### Step 1 · 打开工程

```
Unity Hub → Open → Add project from disk → 选择 platformer-prototype 文件夹
```

首次打开会自动：
- 切 Default Behavior Mode = 2D（Platformer2DSettings）
- 编译脚本 + 导入素材（1-3 分钟）
- 应用像素导入设置（PixelSprites.EnsureImportSettings）

等右下角进度条走完，Console 无红色报错即可。

### Step 2 · 一键搭建场景

菜单栏：`Prototype / 搭建场景 / 全部（Main + Result）`

这会：
1. PixelSprites 批量修正所有素材的 Import Settings
2. 程序化生成长条地面纹理（存到 Assets/Art/Generated/）
3. 创建 Main.unity 和 Result.unity
4. 自动注册进 Build Settings（关键！没这步切场景会报错）

### Step 3 · 打开场景

双击 Project 面板里的 `Assets/Scenes/Main.unity`

### Step 4 · 运行

点顶部绿色 ▶ Play 按钮

### Step 5 · 操作

| 按键 | 动作 |
|---|---|
| A / ← | 向左移动 |
| D / → | 向右移动 |
| 空格 | 跳跃 |
| S / ↓ | 快速下落 |
| T | （若挂 AutoPlayTest）启动自动测试 |

### Step 6 · 通关

走到终点碰到旗帜 `Flag` → 切 Result 场景 → 点「再玩一次」回 Main（分数不触发切场景）

### （可选）端到端验证

```
Prototype / 验证 / M1 通关闭环
```

一键验证从 Main → Result → 回 Main 的完整闭环，输出 PASS/FAIL。

## 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| Console 大量红色报错 | Unity 版本不对 / 首次导入未完成 | 确认 2022.3.62f3c1；等进度条走完 |
| Play 画面黑 / 是 3D 视角 | 2D Default Behavior 没生效 | 重启 Unity；或手动 Edit → Project Settings → Editor → Default Behavior Mode → 2D |
| 分数不动 | 玩家没有 Player 标签 / 收集物 Collider 没勾 IsTrigger | 检查组件 |
| 按空格跳不起来 | 不在 Ground 图层上 / groundMask 配置问题 | 检查 Platform 的 Layer；PlayerController2D.groundMask 留空时自动解析为 Ground |
| 像素模糊 | FilterMode 被设为 Bilinear | 重跑 "搭建场景/全部" 或手动设为 Point |
| 场景切不过去 "Scene could not be loaded" | Main/Result 没注册进 Build Settings | 重跑 "搭建场景/全部"（会自动 EnsureScenesInBuildSettings） |
| 触旗没反应 | Flag 的 Collider2D 没勾 Is Trigger，或玩家不是 Player 标签 | 通关只认 `FlagGoal`；分数达标不再切场景（`WinCondition` 已于 2026-09-30 删除） |
| Play 时 Console 有 MissingReferenceException | 某个 EventBus 订阅者没 Unsubscribe | 查 OnDisable 是否正确 Unsubscribe |

## 开发工作流建议

1. **改代码 → Play 测试 → Stop**：Unity 支持热重载但 Editor 脚本不支持，改 Editor 代码必须重启 Play
2. **改手感参数**：PlayerController2D 的 SerializeField 可以在 Inspector 里实时调，不需要改代码
3. **增收集物**：直接在 Scene 里 AddComponent Collectible2D + FloatAnim + CircleCollider2D IsTrigger
4. **改分数口径**：通关线只有一处——`FlagGoal`（触旗）。`HUD.targetScore`（60）只是进度条参照分与提示切换点；收集物分值改 `SceneSetupHelper` 的 `HeartScore` / `GemScore`；星级分母改 `LevelConfig.totalCollectibles`。改完跑 `Prototype / 验证 / M1 通关闭环`，它按场景实际组件推算期望值，能直接发现三者是否脱节
5. **提交前验证**：Prototype / 验证 / M1 通关闭环 一键跑完整闭环
